# ISOPOD LAB v0.2

## 실행
GitHub Pages, Vercel 또는 로컬 서버에서 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## v0.2 주요 기능
- 초원, 숲, 동굴, 사막, 화산 지역 선택
- 탐험력 기반 지역 해금 및 보상
- 온라인 자동 탐험
- 최대 12시간 오프라인 보상
- 도감 상세, 메모, 즐겨찾기
- 설정 안의 도감 사진 보내기
- 개발자 카카오톡 문의 연결
- 저장 데이터 내보내기/불러오기/초기화
- 기존 localStorage 저장 호환
